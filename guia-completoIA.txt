GUIA COMPLETO — IA REMODELADA
COMO ABRIR
# 1. Navegue ate o diretorio do projeto
cd "E:\IA remodelada"

# 2. Instale dependencias
pip install -r requirements.txt

# 3. Instale o modelo de IA (Ollama)
ollama pull qwen2.5:7b

# 4. Inicie o programa (escolha uma interface):

python agente_cli.py           # Terminal (recomendado para comecar)
python agente_gui.py           # Janela grafica (Tkinter)
python agente_streamlit.py     # Interface web (Streamlit)
python agente_api_server.py    # Servidor REST API
python agente_dashboard.py     # Dashboard Rich no terminal
CAPACIDADES POR INTERFACE
1. TERMINAL (agente_cli.py)
Voce digita comandos, o agente responde e executa ferramentas.

Exemplos:
> Analise o codigo do arquivo main.py
> Crie uma funcao em Python que calcule fibonacci
> Deploy o projeto em Docker
> Compare os modelos qwen2.5:7b e llama3.2:3b
> Crie um PR para a issue #42
> Busque por "database" no codebase inteiro
2. GUI (agente_gui.py)
Janela com caixa de mensagem e area de resposta.
Botao para historico, configuracoes e limpar tela.
3. STREAMLIT (agente_streamlit.py)
Interface web moderna no navegador.
Suporta upload de imagens, historico, configuracoes.
Acesse: http://localhost:8501
4. API (agente_api_server.py)
Servidor REST para integracao com outros sistemas.
Documentacao interativa: http://localhost:8000/docs
Endpoints principais:
  POST /chat          - Enviar mensagem
  POST /chat/stream   - Streaming SSE
  GET  /health        - Health check
  GET  /plugins       - Lista plugins
  GET  /models        - Modelos disponiveis
